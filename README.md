## GitHub Pages deployment

The repository name is expected to be `aimedx-single-player`.

1. Upload all contents of this folder to the repository root.
2. Open repository **Settings > Pages**.
3. Set **Source** to **GitHub Actions**.
4. Open **Actions** and verify `Deploy AIMedX to GitHub Pages` completes successfully.

Do not upload `node_modules` or `dist`.
